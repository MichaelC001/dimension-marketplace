# Product psychology — the ethics contract

The `psych-audit`, `user-empathy`, and `journey-map` skills teach persuasion
techniques (nudges, scarcity, loss aversion, framing). These are inseparable
from the `ethics-check` gate:

- Applying a nudge/scarcity/urgency/framing technique to anything a user will
  SHIP or PUBLISH → run the `ethics-check` skill's quick gate first (Regret
  test · scarcity authenticity · defaults-for-the-user). Never emit false
  urgency or fake scarcity.
- Recommendations must use psychology vocabulary with the named principle
  (e.g. "fails Filter: reads high-effort — Hick's Law"), never bare opinion.
- These frameworks (Imprint Loop, Action Map, Charge) are heuristics built on
  public behavioral science, not laws — frame confidence accordingly and
  prefer testable claims.
